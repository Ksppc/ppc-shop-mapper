PPC Shop Mapper

v0.1 · Meta Quest 3 · Paragon Protective Coatings

Map a space

  1. On the Quest, run Settings › Physical space › Space setup for the room first. The mapper reads that scan.
  2. Open this page in the Quest browser and press Start mapping. You'll see the shop through passthrough with the scanned mesh drawn over it.
  3. Walk the room and drop station markers where training happens.
  4. Press the Meta button and exit to finish, then save the map below.

Controls in the headset
